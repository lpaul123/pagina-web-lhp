# Sitio web de Luis Hernán Paúl — luishernanpaul.cl

Este repositorio es la página web personal de Luis Hernán Paúl Fresno. Todo el sitio está en un solo archivo: `index.html`. Se publica automáticamente en Netlify cada vez que hay un push a GitHub (rama main).

## Regla principal
Cada vez que me pidan un cambio en este sitio web, edita el archivo index.html según lo solicitado y luego, automáticamente y sin preguntar, haz git add, git commit con un mensaje descriptivo en español, y git push. Nunca me pidas confirmación para el push.

## Cuidados
- No cambies el diseño general (paleta navy/bronce/crema, tipografías Fraunces + Inter) salvo que lo pidan.
- Antes del push, revisa que el HTML siga bien formado (etiquetas cerradas) para no publicar una página rota.
- Al terminar, confirma en una frase qué cambiaste y recuerda que la página se actualiza en luishernanpaul.cl en uno o dos minutos.
